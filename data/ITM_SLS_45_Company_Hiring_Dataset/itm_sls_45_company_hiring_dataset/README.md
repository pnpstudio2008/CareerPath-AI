# ITM SLS Baroda University — 45-Company Synthetic Hiring Dataset

This package maps the 45 synthetic candidates from the Resume Analyzer dataset to **45
distinct companies**, with one synthetic job requirement per company.

### Important
The ITMBU website publicly lists numerous recruiters and describes a placement flow that
includes aptitude/technical testing and interviews. Some company names in this demo are
real organisations appearing in those public materials; however, the candidate-company
matches, scores, job descriptions and hiring outcomes in this package are **synthetic**.
They must not be presented as actual placement records.

### Contents
- `45_company_hiring_map.csv`
- `45_company_hiring_map.json`
- `candidates_with_45_companies.csv`
- `job_requirements/` — 45 individual job requirement files

### Recommended AI/ML demo
For an uploaded resume:
1. Extract resume text.
2. Extract skills/entities.
3. Compare the resume with all 45 job requirements.
4. Calculate similarity / match score.
5. Rank companies.
6. Show matched skills and missing skills.
7. Recommend the best-fit roles.
